🔥 Cấu hình Firebase

File này đã có sẵn Firebase SDK. Bạn chỉ cần tạo project, bật Realtime Database và thay firebaseConfig ở cuối file.

  1. Vào Firebase Console → tạo project mới.
  2. Trong Project Overview → thêm một Web app (</>).
  3. Firebase sẽ đưa cho bạn đoạn firebaseConfig. Copy 7 trường vào file.
  4. Vào Build → Realtime Database → Create Database.
  5. Chọn location gần bạn, sau đó chọn Start in test mode nếu đây chỉ là project cá nhân.
  6. Lưu file HTML, mở lại. Góc Firebase sẽ báo trạng thái kết nối.

Cảnh báo: “không cần bảo mật” vẫn có nghĩa là bất kỳ ai có URL/database reference đều có thể sửa dữ liệu nếu bạn để rules công khai. Với đúng yêu cầu của bạn, test mode là đơn giản nhất; đừng dùng database công khai cho dữ liệu nhạy cảm.

Nếu muốn chia dữ liệu theo từng trình duyệt mà không cần tài khoản, code đã tạo một deviceId trong localStorage và lưu dưới nhánh đó.
